## 1. Product Overview — что это за продукт

**Факт.** Teleiosis — мобильное приложение для самостоятельного обучения на материалах, которые пользователь собирает сам. Личная библиотека хранит ссылки, заметки и PDF. После входа экран «Сегодня» предлагает ближайшее занятие, показывает карточки к повторению и прогресс недели. Пользователь может связать материалы с долгосрочными целями, запланировать занятия, отметить изученное и записать главную мысль. ## 2. Core Value Proposition — основная ценность

**Интерпретация по реализованным сценариям.** Приложение помогает выбрать, чем заняться сейчас из сохранённого, и зафиксировать результат. «Сегодня» предлагает следующий шаг с учётом плана и состояния библиотеки. Если у пользователя есть ограниченное время, он может запросить подборку на 5, 15, 30 или 60 минут. После занятия можно отметить материал изученным, записать главную мысль и создать вопрос для последующего повторения. [Экран «Сегодня»](mobile/src/learning/Today.tsx) · [Подбор по времени](mobile/src/learning/TimeBudget.tsx) · [Завершение изучения](mobile/src/learning/Completion.tsx)

**Открыто для проверки.** По реализации нельзя определить, какая часть цикла ценнее для пользователей, повышает ли она регулярность занятий и влияют ли карточки на запоминание.

## 4. Current Features — реализованный функционал

| Область | Возможности |
| --- | --- |
| Аккаунт | Регистрация с согласием, вход по e-mail и паролю, выход, подтверждение адреса, сброс и смена пароля и удаление аккаунта. Есть обработка ссылок из писем, редактирование имени, настройка недельной нормы и выбор русского или английского языка интерфейса. |
| Добавление | Ввод или вставка ссылки из буфера, предпросмотр при доступности метаданных, заметка и выбор категории или коллекций. Поддерживается приём ссылки или текста через системное «Поделиться». С экрана добавления можно напрямую открыть формы заметки и PDF. После синхронизации ссылки её можно привязать к цели. |
| Библиотека | Основной поиск по названию, расширенный онлайн-поиск по названию, описанию, заметке и URL. Категории представлены быстрыми чипами. Есть сортировка, фильтры, постраничная загрузка и выбор нескольких карточек для удаления. |
| Организация | Создание, переименование и удаление категорий и управление приватными тегами и коллекциями. У материала может быть одна категория. К материалу можно привязать несколько групп. Фильтры по тегу и коллекции комбинируются с остальными условиями. |
| Карточка | Просмотр и открытие оригинала или PDF, редактирование, включая URL для ссылок, назначение категорий, тегов, коллекций и целей, удаление материала. Из карточки доступны планирование, завершение изучения и повторение. |
| Сегодня | Ближайшее занятие с причиной выбора и длительностью, когда она известна. Есть входы в повторение, недельный план, прогресс, добавление и библиотеку. |
| Подбор по времени | Пресеты 5, 15, 30 и 60 минут. Пресет на «Сегодня» сразу запускает подбор. Сервер предлагает один основной вариант и до двух альтернатив среди непросмотренных или запланированных материалов с известной длительностью в пределах выбранного бюджета. В выдаче учитываются наступившие задания и связи с активными целями. |
| Долгосрочные цели | Название, необязательный ожидаемый результат, статусы активной, завершённой и архивной цели. Детали показывают ожидаемый результат, прогресс и ближайший актуальный материал. Можно выбрать несколько материалов через отдельный поиск, запланировать занятие из цели, архивировать цель или окончательно удалить её с подтверждением. Для множественного добавления и удаления цели требуется API с соответствующими маршрутами. |
| Завершение изучения | Подтверждение статуса «Изучено» с возможностью завершить одно связанное задание. После подтверждения можно сохранить отдельную от заметки главную мысль, создать вопрос для повторения или перейти к выбору следующего материала. |
| Возврат к материалам | Можно назначить напоминание по материалу, включить напоминания и задать время ежедневной подборки и часовой пояс. Приём push на устройстве в текущей конфигурации не подтверждён. |
| Прогресс | Неделя, месяц и всё время, недельная цель по числу изученных материалов, серия дней и недавние материалы. Базовая статистика библиотеки доступна дополнительно. |
| Недельный план | Бюджет минут на конкретную неделю. Задания связывают материал с целью и имеют дату, приоритет и ручную оценку длительности. Расписание группирует задания по дням и выделяет текущий день в часовом поясе аккаунта. Перенос открывает календарь, завершение требует подтверждения. |
| Повторение | Ручные карточки «вопрос — ответ». Из «Сегодня» открывается сессия, которая показывает наступившие карточки по одной и подводит итог по подтверждённым ответам. В общем списке доступны история, перенос даты и пауза. «Помню» увеличивает интервал, «Не помню» сбрасывает его и оставляет карточку на сегодня. |
| Перенос данных и офлайн | Экспорт JSON через средства ОС, импорт собственного JSON с предпросмотром. Кэш библиотеки, «Сегодня» и подбора, очередь создания ссылок и заметок, локальный черновик главной мысли. |

Общие статусы материала — «Не просмотрено», «Запланировано», «Изучено» и «Неактуально». Источник и тип определяются по ссылке, например для YouTube и Telegram. Сервер пытается получить метаданные внешней страницы. Текущий мобильный список при наличии данных показывает длительность видео или приблизительные минуты чтения статьи, заметки или PDF. ## 5. User Flows — основные пользовательские сценарии

1. **Начать с «Сегодня».** После входа приложение открывает главный экран. Сначала он предлагает незавершённое задание с наступившим сроком. При его отсутствии предлагает запланированный или непросмотренный материал из библиотеки. Там же видны недельный прогресс и карточки к повторению. В пустой библиотеке доступно добавление первого материала. [Экран «Сегодня»](mobile/src/learning/Today.tsx) · [Правила выбора](app/routers/learning.py)
2. **Сохранить найденное.** Пользователь открывает «Добавить» из «Сегодня» или библиотеки, вставляет URL либо передаёт ссылку или текст через «Поделиться». Входящий черновик можно назначить аккаунту после входа. Форма показывает состояние локальной записи или отправки на сервер и помогает обработать ошибки. При повторном сохранении URL приложение сообщает о дубле. [Форма ссылки](mobile/src/app/add-link.tsx) · [Входящие материалы](mobile/src/library/PendingMaterials.tsx)
3. **Выбрать занятие по времени.** Пользователь нажимает пресет на «Сегодня» и получает основной вариант и до двух альтернатив. Из подборки можно открыть карточку и затем оригинал или PDF. [Подбор по времени](mobile/src/learning/TimeBudget.tsx)
4. **Работать над целью.** На вкладке «Цели» пользователь создаёт цель, при желании описывает результат и привязывает материалы из библиотеки. Связь можно добавить и из карточки материала. Пользователь может сразу запланировать связанный материал, задав дату, приоритет и минуты. Задания видны в недельном плане. [Интерфейс целей](mobile/src/learning/goals.tsx) · [Недельный план](mobile/src/app/plan.tsx)
5. **Завершить изучение.** Пользователь нажимает «Отметить изученным» в карточке или принимает подсказку после возврата из внешнего источника. Если он открыл материал из конкретного задания, приложение сохраняет этот контекст. При входе из библиотеки пользователь может явно выбрать одно открытое задание активной цели. После подтверждения экран показывает «Материал изучен». Пользователь может открыть поле главной мысли, создать вопрос для повторения или выбрать следующий материал. [Карточка](mobile/src/app/library/%5Bid%5D.tsx) · [Завершение изучения](mobile/src/learning/Completion.tsx)
6. **Повторить материал.** Из «Сегодня» пользователь открывает карточки, срок которых наступил, раскрывает ответ и выбирает «Помню» или «Не помню». Сервис обновляет дату следующего повторения и сохраняет ответ в истории. Карточки конкретного материала доступны из его деталей. [Экран «Сегодня»](mobile/src/learning/Today.tsx) · [Экран повторения](mobile/src/app/review.tsx)
7. **Настроить напоминания или перенести библиотеку.** Пользователь включает напоминания, задаёт время и часовой пояс, при необходимости назначает дату для материала. Для писем нужен подтверждённый адрес. Дайджест выбирает до пяти материалов, начиная с запланированных. В «Профиль → Пароль и данные» доступны импорт JSON с предпросмотром, экспорт и удаление аккаунта. [Расписание](mobile/src/app/reading-schedule.tsx) · [Правила подборки](app/digest.py) · [Управление данными](mobile/src/app/preferences.tsx)

## 6. Information Architecture — структура и навигация

В нижней навигации четыре вкладки.

- **Сегодня**. Главный экран после входа. Ближайшее занятие, подбор по времени, повторение, прогресс недели, переходы к плану, добавлению и библиотеке.
- **Библиотека**. Поиск, фильтры, входящие материалы, добавление, карточка материала, категории, теги и коллекции.
- **Цели**. Долгосрочные цели, их материалы, планирование из цели и переход к экрану «Прогресс».
- **Профиль**. Недельная норма, напоминания, время и часовой пояс, язык, безопасность и «Пароль и данные».

«Добавить» и «Прогресс» открываются как отдельные экраны. После выхода приложение показывает экран входа. [Вкладки](mobile/src/app/%28tabs%29/_layout.tsx) · [Маршруты](mobile/src/app/_layout.tsx)

**Связи между сущностями.** У материала может быть одна категория, несколько тегов, коллекций и целей, одно активное напоминание, одна главная мысль и несколько карточек для повторения. Задание связывает материал, цель и конкретный день. Материал можно привязать к цели без задания. Отвязка сохраняет материал и существующие задания, архивирование цели сохраняет её задания и историю. Постоянное удаление убирает цель, её связи, задания и историю. Материалы и их связи с другими целями сохраняются. [Модели данных](app/models.py) · [Контракт целей](app/routers/learning_goals.py)

## 7. UX Observations — наблюдения по интерфейсу

- **Сохранение происходит в несколько этапов.** Мобильная форма различает локальную запись и добавление на сервер. Входящие черновики можно обработать в библиотеке, а сбои отправки — на экране «Добавить». Предпросмотр ссылки загружается отдельно, поэтому отсутствие картинки или названия не блокирует сохранение. [Форма ссылки](mobile/src/app/add-link.tsx) · [Черновики](mobile/src/library/PendingMaterials.tsx)
- **Ближайшее занятие и повторение получили прямые входы.** «Сегодня» показывает причину выбора и различает пустую библиотеку, отсутствие актуальных материалов и занятие, запланированное на будущее. Категории видны сразу в библиотеке, фильтры по тегам и коллекциям раскрываются дополнительно. Действия для цели или плана также доступны из карточки материала. [Экран «Сегодня»](mobile/src/learning/Today.tsx) · [Библиотека](mobile/src/app/%28tabs%29/library.tsx) · [Карточка](mobile/src/app/library/%5Bid%5D.tsx)
- **Множественный выбор в библиотеке.** Долгое нажатие на карточку включает режим выбора. После подтверждения приложение удаляет материалы по одному. Если серия прерывается, неподтверждённые позиции остаются выделенными для повтора. [Библиотека](mobile/src/app/%28tabs%29/library.tsx) · [Проверки](docs/mobile_testing.md)
- **Показатели отражают разные действия.** Недельная норма считает изученные материалы. Прогресс долгосрочной цели считает уникальные связанные материалы и исключает «Неактуально». План считает завершённые задания и отдельно суммирует их оценки в минутах. Подбор использует длительность самого материала, а чтение оценивается по объёму текста. Для фактического времени занятий данных нет. Статус «Изучено» и ответы по карточкам основаны на действиях пользователя. Снятие статуса сбрасывает дату изучения в статистике и сохраняет завершённое задание, карточки и главную мысль. [Статистика](app/stats.py) · [Цели](app/routers/learning_goals.py) · [План](app/routers/week_plan.py) · [Оценки длительности](app/duration.py)
- **Интерфейс моделирует ошибки и пустые состояния.** Есть сообщения при отсутствии результатов, устаревших данных и проблемах сети, временное отключение недоступных действий и подтверждения удаления. В коде есть подписи и роли для вспомогательных технологий. Проверка удобства, TalkBack, VoiceOver и крупных размеров текста требует отдельной ручной приёмки. ## 8. Technical Constraints — технические ограничения

| Факт или техническое наблюдение | Следствие для развития |
| --- | --- |
| Приложение использует React Native, TypeScript, Expo и Expo Router. Серверная часть использует FastAPI, SQLAlchemy, PostgreSQL и миграции Alembic. | Новые поля и функции могут требовать миграции базы данных и согласованного обновления API и клиентской сборки. |
| Приложение использует Bearer-сессии, SecureStore для учётных данных сессии и SQLite для локального кэша и очереди. Для ряда мобильных операций предусмотрены проверка версии и ключи повторяемости. | При расширении офлайна важны изоляция кэша и очереди по аккаунту, срок сессии, повтор после потери связи и конфликт правок с другого устройства. |
| «Поделиться» и ссылки приложения зависят от платформенной конфигурации. Есть Android intent и iOS share extension. | Проверки JavaScript не заменяют проверку платформенных сценариев в сборке, на физическом устройстве и с релизной подписью. |
| Уведомления обслуживает отдельный воркер. Сервер различает консольный режим, перехват писем для стенда и SMTP. Реальная почта требует настройки отправителя и проверки доставки. Серверный адаптер RuStore требует конфигурации, клиентская интеграция остаётся открытой. | Сброс пароля, верификация, дайджест и напоминания зависят от состояния среды. Их готовность определяется сквозной проверкой каждого канала. |
| PDF включается настройкой сервера и требует хранилища и антивирусной проверки. Приватный локальный диск поддержан для тестовых сред, текущая конфигурация `prod` требует S3-совместимого хранилища. | Нужно учитывать совместное резервирование и восстановление БД и файлов, лимиты хранения и доступность сканера. При сбое сканера загрузка недоступна. |

**Внутренняя аналитика.** В коде реализованы события сохранения, изучения, целей, повторения и взаимодействия с «Сегодня» и подбором. События хранятся в PostgreSQL. Агрегированный отчёт рассчитывает активацию за семь дней, переход от сохранения к изучению, возвраты и открытие материалов из подбора. В тестовом APK 0.15.0 включена клиентская отправка, серверный сбор на стенде выключен. Базовых показателей внешнего пилота пока нет. [Реализация аналитики](docs/learning_product_implementation.md#e5-внутренняя-аналитика-и-подготовка-пилота) · [Журнал проверок](docs/mobile_testing.md)

## 9. Known Limitations — ограничения текущей реализации

- **Вне сети доступны загруженные данные и отдельные черновики.** «Сегодня» и подбор показывают ранее сохранённый снимок с отметкой об устаревании. Ссылки и заметки можно поставить в очередь. Черновик главной мысли хранится локально и отправляется по явной команде после восстановления сети. Подтверждение изучения, управление целями и заданиями, ответы на карточки, загрузка PDF и расширенный поиск требуют сети. [Кэш](mobile/src/offline/cache.ts) · [Реализация учебного цикла](docs/learning_product_implementation.md)
- **Поиск работает по сохранённым полям.** Расширенный поиск — совпадение подстроки без учёта регистра. Содержимое оригинальной страницы и PDF в поиск не входит. Метаданные и оценки длительности зависят от доступности источника и наличия извлекаемых данных. [API поиска](app/routers/contents.py) · [Метаданные](app/metadata.py)
- **Экспорт и импорт имеют разный охват.** Импорт принимает собственный JSON Teleiosis v1, до 2 МиБ и 500 материалов на файл, и восстанавливает библиотеку и её организацию. Экспорт также содержит цели и связи, план, главные мысли и карточки. Импорт эти данные не восстанавливает. JSON хранит сведения о PDF, а при переносе PDF-карточка становится заметкой. [Экспорт](app/export.py) · [Импорт](app/library_import.py)
- **PDF ограничен одним файлом на карточку, до 10 МиБ на файл, 20 PDF и 100 МиБ на аккаунт.** Повреждённые, зашифрованные и активные документы отклоняются. Просмотр передаётся средствам ОС. На стенде загрузка, сканирование и скачивание синтетического PDF прошли сквозную проверку, при этом Docker сообщает, что сканер имеет статус `unhealthy`. Локальная диагностика связала этот статус с проверкой TCP при настроенном Unix-сокете. Проверка по сокету прошла локально, её применение на стенде остаётся открытым. [Хранилище](app/pdf_storage.py) · [Контракт PDF](docs/mobile_pdf.md) · [Проверка стенда](docs/staging.md)
- **Каналы напоминаний и покрытие устройств ограничены.** Push выключен по умолчанию, доставка RuStore/APNs на устройства не подтверждена. Документация стенда описывает перехват почты, а SMTP на реальных почтовых ящиках остаётся открытым. Приёмка отдельных функций на Samsung S25 не закрывает приёмку iOS и остальных Android-конфигураций. [Настройки сервера](app/config.py) · [План первого выпуска](docs/mobile_first_free_release.md) · [Матрица проверок](docs/mobile_release_checklist.md)
- **Часть сценариев отложена.** В текущем коде нет социального входа, ИИ-анализа и подписки. Планирование и создание карточек выполняются вручную. Решение о бесплатном первом релизе зафиксировано, долгосрочная коммерческая модель остаётся открытой. [План выпуска](docs/mobile_first_free_release.md) · [Журнал проверок](docs/mobile_release_checklist.md)
