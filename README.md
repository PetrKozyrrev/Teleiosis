# Teleiosis

Сервис для сбора, организации и изучения полезного контента.
Веб-сайт + Backend API (FastAPI) + PostgreSQL.

Статус: в разработке (MVP). Готовы backend (материалы, категории, метаданные, вход по e-mail и паролю, сброс пароля) и каркас сайта со страницами входа. Библиотека на сайте, напоминания и статистика ещё не реализованы.

Документация: папка docs (requirements, architecture решения в decisions, database, api, setup, progress). Запуск: docs/setup.md.
