# Teleiosis

Сервис для сбора, организации и изучения полезного контента.
Веб-сайт + Backend API (FastAPI) + PostgreSQL + процесс напоминаний (воркер).

Статус: в разработке (MVP). Готовы: регистрация и вход, сброс пароля, подтверждение e-mail, библиотека с поиском и фильтрами, карточка материала, категории, закладка браузера, настройки (часовой пояс, время, смена пароля), статистика («Прогресс»), ежедневная подборка и напоминания по материалам (пока режим console), отписка, метрики закрытого тестирования, редизайн интерфейса в палитре бренда (подэтап 8.0).

Документация: папка docs (requirements, architecture решения в decisions, database, api, setup, progress). Запуск: docs/setup.md.
