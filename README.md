# Teleiosis

Сервис для сбора, организации и изучения полезного контента.
Веб-сайт + Backend API (FastAPI) + PostgreSQL + процесс напоминаний (воркер).

Статус: в разработке (MVP), этап 8 (подготовка к закрытому тестированию). Готовы: регистрация и вход, сброс пароля, подтверждение e-mail, библиотека с поиском и фильтрами, карточка материала, категории, закладка браузера, настройки (часовой пояс, время, смена пароля), статистика («Прогресс»), ежедневная подборка и напоминания по материалам (пока режим console), отписка, метрики закрытого тестирования, выгрузка данных и удаление аккаунта, редизайн интерфейса в палитре бренда.

Документация: папка docs (requirements, decisions, database, api, setup, progress, pricing). Запуск: docs/setup.md.
