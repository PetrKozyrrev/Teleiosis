# Teleiosis

Сервис для сбора, организации и изучения полезного контента.
Веб-сайт, мобильный каркас Android/iOS, Backend API (FastAPI), PostgreSQL и процесс напоминаний (воркер).

Статус на 16.11.2026: веб-MVP прошёл закрытый локальный тест (по сообщению основателя критических ошибок нет); приватный серверный стенд подготовлен, публичный запуск и внешнее тестирование ещё не выполнены. Готовы: регистрация и вход, сброс пароля, подтверждение e-mail, библиотека с поиском и фильтрами, карточка материала, категории, закладка браузера, настройки (часовой пояс, время, смена пароля), статистика («Прогресс»), ежедневная подборка и напоминания по материалам (SMTP в коде есть, доставка на сервере не проверена), отписка, метрики закрытого тестирования, выгрузка данных и удаление аккаунта, редизайн интерфейса в палитре бренда.

Авторизация по e-mail/паролю: web-сессии в HttpOnly cookie, mobile-сессии отдельного типа через opaque Bearer. Код бота и Telegram Mini App удалён; Telegram-ссылки можно сохранять как раньше. Для существующей базы подготовлена миграция j1f3a5b7c9d0 (см. docs/setup.md).

Утверждён план Android/iOS для российского рынка: React Native + TypeScript + Expo, общий backend, кэш и очередь новых ссылок/заметок, приём через «Поделиться», push. В блоке 1 на сервере Timeweb Cloud в РФ подготовлен закрытый staging на домене teleiosistest.tw1.ru: приватный перехват писем, отдельный gateway-вход, egress и backup/restore. Проверены 741 тест и закрытые HTTPS-сценарии; публичный proxy и реальная SMTP-доставка ещё не включены. По решению пользователя начат мобильный блок 2: [каркас приложения](mobile/README.md) на SDK 58 с навигацией и проверками share/SecureStore; В блоке 3 добавлена авторизация: [контракт и проверки](docs/mobile_auth.md), APK0.2 и приватный API готовы. Библиотека относится к следующему блоку. Установка на устройства и полная приёмка блока открыты: [матрица](docs/mobile_testing.md). Реализация выполняется по одному блоку с остановкой на приёмку.
