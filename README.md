# Teleiosis

Сервис для сбора, организации и изучения полезного контента.
Веб-сайт + Backend API (FastAPI) + PostgreSQL + процесс напоминаний (воркер).

Статус на 16.11.2026: веб-MVP прошёл закрытый локальный тест (по сообщению основателя критических ошибок нет); серверный деплой и внешнее тестирование ещё не выполнены. Готовы: регистрация и вход, сброс пароля, подтверждение e-mail, библиотека с поиском и фильтрами, карточка материала, категории, закладка браузера, настройки (часовой пояс, время, смена пароля), статистика («Прогресс»), ежедневная подборка и напоминания по материалам (SMTP в коде есть, доставка на сервере не проверена), отписка, метрики закрытого тестирования, выгрузка данных и удаление аккаунта, редизайн интерфейса в палитре бренда.

Авторизация только по e-mail и паролю, сессии в HttpOnly cookie. Код бота и Telegram Mini App удалён; Telegram-ссылки можно сохранять как раньше. Для существующей базы подготовлена миграция j1f3a5b7c9d0 (см. docs/setup.md).

Утверждён план Android/iOS для российского рынка: React Native + TypeScript + Expo, общий backend, кэш и очередь новых ссылок/заметок, приём через «Поделиться», push. После документальной части блока 0 подтверждён блок 1: подготовлены контейнеры API/worker/БД/HTTPS-прокси, backup/restore и CI. Хостинг/домен/SMTP/бюджет пока не выбраны, внешний деплой не выполнен. Mobile-кода ещё нет. Реализация выполняется по одному блоку с остановкой на приёмку.
