# Варианты инфраструктуры пилота (РФ)

## Рекомендуемый старт

Одна Linux VM в российском регионе для API/worker/PostgreSQL/Caddy и отдельное российское хранилище зашифрованных резервных копий. Начальная инженерная гипотеза — 2 vCPU / 4 ГБ RAM / 40–60 ГБ SSD. Это не результат нагрузки и не гарантия ёмкости; Argon2 потребляет память, четыре параллельных хэша нужно учесть. Managed PostgreSQL и отдельный app-сервер — следующий вариант, если основатель выбирает меньше административной работы за больший бюджет; compose тогда адаптируется отдельно.

| Кандидат | Почему рассмотреть | Что проверить до оплаты |
|---|---|---|
| Timeweb Cloud, только российский регион | VM и калькулятор ресурсов; простой кандидат для малого стенда | Итог 2/4/SSD, публичный IPv4, российское размещение копий, сеть SMTP/ACME, договоры и поддержка firewall |
| Selectel, российский регион | Облачные серверы с настраиваемыми ресурсами, калькулятор | Полная цена CPU/RAM/диска/IP/сети/бэкапов; регион; администрирование и требования к оператору |
| Yandex Cloud | Вариант, если нужны связанные облачные сервисы/managed DB и Postbox | Отдельная стоимость VM/диска/IP/БД, сложность IAM, российский регион и правила сервиса |

Источники: [Timeweb Cloud VM](https://timeweb.cloud/services/cloud-servers), [калькулятор](https://timeweb.cloud/prices), [Selectel VM](https://docs.selectel.ru/cloud-servers/about/about-cloud-server/), [стоимость Selectel](https://selectel.ru/prices/). Не сравнивать рекламный минимальный тариф с полной конфигурацией и не фиксировать цену без выбранного региона/периода. Точные суммы требуется получить в калькуляторах перед выбором; оплачивать год вперёд для первого пилота не требуется.

## Почта

Первым кандидатом предлагается транзакционный Yandex Cloud Postbox: SMTP совместим с существующим smtplib-кодом, стоимость зависит от объёма. До выбора проверить российский регион, допуск проекта/домен отправителя, ограничения, данные получателей, квоты, TLS, IAM/учётные данные и DNS (SPF/DKIM/DMARC). Самостоятельный почтовый сервер для пилота не предлагается из-за доставляемости и администрирования.

Источники: [Postbox quickstart/SMTP](https://yandex.cloud/en/docs/postbox/quickstart), [тарификация](https://yandex.cloud/ru/docs/postbox/pricing). Провайдер и настройки в код не зашиты; другой транзакционный SMTP допустим после проверки тех же условий. Отправка напоминаний и юридическая квалификация сообщений согласуются отдельно, наличие SMTP-аккаунта не заменяет эту проверку.

## Что подтвердить для серверного продолжения блока 1

Основатель выбирает месячный предел расходов на VM/IP + отдельные копии + почту + домен, подтверждает провайдера/регион и права оператора. После этого создаётся конкретная конфигурация для приёмки; секреты вводятся вне чата. Юрист проверяет оператора, договоры, уведомления/согласия и потоки данных до внешнего пилота. Доступы, аккаунты или согласие на покупку из наличия этого списка не следуют.

До выбора продолжать можно локальные проверки контейнеров/миграций/backup; реальный HTTPS, доступность внешних ресурсов из ДЦ и доставка писем остаются открытыми. Порядок развёртывания: [deployment.md](deployment.md).
