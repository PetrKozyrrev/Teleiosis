# Блок 10. Цели и ручной недельный план

22.11.2026 пользователь принял создание PDF на S25 и разрешил переход к блоку 10. Расчёт прогресса по числу заданий согласован отдельно.

Неделя начинается в понедельник. Для текущей недели API берёт календарную дату в часовом поясе аккаунта. У задания есть дата, цель, материал из своей библиотеки, приоритет и ручная оценка 1–1440 минут. Один материал можно запланировать один раз на цель, в другой цели у него может быть своё задание. Бюджет задаётся на конкретную неделю в минутах. Превышение показывает рекомендацию пересмотреть нагрузку. Следующее открытое задание выбирается по приоритету, дате и порядку создания.

Прогресс — число выполненных заданий среди заданий выбранной недели. Одно из двух даёт 50%, даже если их оценки 10 и 50 минут. Для пустой недели показывается «Пока нет заданий». Перенос между неделями меняет оба знаменателя. Завершение фиксируется один раз и оставляет статус материала в библиотеке прежним. Завершённое задание остаётся за назначенной неделей. Удаление задания, цели или материала исключает соответствующие задания из плана и его статистики. Удаление цели сохраняет материалы.

Записи выполняются онлайн под текущим аккаунтом. Отдельный API под /mobile/plan использует действующий мобильный шлюз. План и история изменений входят в выгрузку аккаунта при наличии записей. Импорт JSON v1 по-прежнему переносит библиотеку.

## Экран и API

В «Прогресс → Недельный план» можно создать цель, задать бюджет и переключать недели. В библиотеке открыть сохранённую карточку и выбрать «Добавить в недельный план». При создании задания выбрать цель, приоритет, дату и оценку в минутах. Из недельного списка можно открыть материал, перенести, завершить или убрать задание.

| Запрос | Действие |
| --- | --- |
| GET /mobile/plan?day=YYYY-MM-DD | Неделя указанного дня, цели, задания, бюджет, выполненные и запланированные минуты, следующее задание |
| POST /mobile/plan/goals | Создание по имени, повтор возвращает ту же цель. До 100 целей на аккаунт, имя до 100 символов |
| DELETE /mobile/plan/goals/{id} | Удаление цели со всеми её заданиями после подтверждения в приложении |
| PUT /mobile/plan/weeks/{monday}/budget | Минуты от 1 до 10080, previous содержит увиденное значение или null. Конфликт возвращает 412 |
| POST /mobile/plan/tasks | goal_id, content_id, day, minutes, priority (1 — высокий, 2 — обычный, 3 — низкий). Совпадающий повтор возвращает исходное задание. Другая конфигурация того же материала в цели возвращает 409 |
| PUT /mobile/plan/tasks/{id}/day | Перенос открытого задания. Тело содержит day |
| PUT /mobile/plan/tasks/{id}/complete | Завершение. Повтор сохраняет момент завершения |
| DELETE /mobile/plan/tasks/{id} | Удаление одного задания |

Изменения существующего задания требуют заголовок If-Match с версией в кавычках. При расхождении версии сервер отвечает 412. Если запрошенный результат уже достигнут, повтор завершения или переноса возвращает текущее состояние. Составные внешние ключи проверяют владельца материала и цели. Операция и запись истории выполняются в одной транзакции. Даты принимаются в формате YYYY-MM-DD за 1900–2100 годы. При пустом бюджете можно планировать задания и видеть сумму минут.
