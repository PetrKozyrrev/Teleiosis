# Общее тестирование и подготовка выпуска, блок 8

## Решение от 19.11.2026

Пользователь разрешил продолжить с переносом реальных проверок RuStore на общее тестирование. Разрешена подготовка блока 8 с открытыми задачами блока 7. Публичный выпуск, отправка на модерацию, платные услуги, rollout стенда, коммит и git push согласуются отдельно. Блоки 9–13 не начаты.

Последняя подтверждённая на S25 версия — APK 0.5.1. Push выключен, SDK в приложение не подключён, APNs не реализован. Последний backend-прогон — 794 теста, включая 25 push-проверок с заменённым отправителем. Эти проверки не подтверждают получение уведомления телефоном. Текущая подготовка не означает готовность приложения к выпуску.

## Что доделать до проверки push

Подготовка сборки/CI и локальный нагрузочный ориентир выполнены отдельно от push. Результаты, версии и оставшиеся замечания npm audit собраны в [mobile_release.md](mobile_release.md). Кандидат 0.5.2/code10 требует проверки обновления на S25. Локальные команды не заменяют ещё не запущенный GitHub Actions и физический iPhone.

| ID | Задача | Состояние | Условие завершения |
|---|---|---|---|

## Отложенные проверки push

Все строки ниже **открыты**. Выполняются после соответствующих D/R-зависимостей. Основное Android-устройство — Samsung S25, Android 17 / One UI 9.0 по ответу пользователя 19.11.2026. Для push требуется отдельно подтвердить установленный RuStore и его версию. Для iOS нужен физический iPhone. Проверки Android без GMS и других дистрибьюторов не считаются пройденными на основании результата S25.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| P1 | Тест из консоли, затем настоящее серверное напоминание и ежедневная подборка | Уведомления получены на устройстве. HTTP 200 записан отдельно от факта доставки |
| P2 | Первый отказ permissions, повторное включение из настроек ОС, выключенный канал | Нет повторяющихся запросов разрешения. Библиотека и очередь продолжают работать. Состояние канала соответствует ОС |
| P3 | RuStore отсутствует, устарел или ограничен в фоне | Понятное сообщение и рабочее приложение, без падения и бесконечного ожидания |
| P4 | Приложение открыто, в фоне, процесс уничтожен, телефон перезагружен | Проверена доставка в каждом состоянии. Нажатие ведёт к нужной карточке без повторного перехода. Ограничения принудительной остановки ОС фиксируются отдельно |
| P5 | Нажатие после истечения сессии, выхода или смены аккаунта | Требуется вход. Чужая карточка и данные не раскрываются, старый переход не открывает материал другого аккаунта |
| P6 | Переустановка/обновление, ротация токена, два устройства | Актуальные привязки, по одной квитанции события на устройство. Старый токен не получает новые сообщения |
| P7 | Logout, reset/change password с отзывом других сессий, удаление аккаунта | Отозванные устройства отвязаны. Новые отправки на них прекращены. Уже принятое провайдером сообщение может прийти, доступ к данным всё равно закрыт |
| P8 | Материал изучен/удалён, напоминание отменено/перенесено до retry | Очередная попытка не отправляет устаревшее напоминание, удалённая карточка обрабатывается понятно |
| P9 | Нет сети, тайм-аут, 429/5xx, перезапуск и простой worker | Задержки и lease соблюдены, после TTL нет отправок. Невалидный токен отключён. Ошибка ключа не удаляет корректные токены. Неопределённый ответ провайдера и возможный дубль отражены в результате |
| P10 | Смена часового пояса/времени, граница суток, простой дольше TTL | Подборка актуального дня, без старых событий до opt-in. Время и ограничения доставки документированы |
| P11 | Почта и push по отдельности и вместе, два устройства | Каналы включаются явно. Нет неожиданного включения второго канала. Рассылка на два выбранных устройства ожидаема и объяснима |
| P12 | Wi-Fi/мобильная сеть РФ, энергосбережение и блокировка экрана S25 | Записаны факт/задержка доставки и настройки ОС/RuStore. Условия, при которых доставка не подтверждена, не скрыты |
| P13 | Payload, журналы, запросы через staging-шлюз, APK | Нет текста заметки, URL, почты и сервисного секрета в push/логах/APK. Пароль шлюза удалён до API, Bearer сохраняется, изоляция двух аккаунтов проверена |
| P14 | APNs на iPhone | Повторены P1–P13 в применимых состояниях iOS, включая permissions, фон, холодный запуск, APNs environment и подпись |

## Как фиксировать результат

Для каждого ID записывать дату, commit/состав рабочего дерева, версию и SHA-256 APK/IPA, устройство/ОС, SDK и RuStore, окружение APNs, состояние сети/процесса/permissions, синтетические аккаунты A/B, шаги, ожидание, факт и ссылку на обезличенное доказательство. Секреты и device token не записывать. Backend acceptance и факт приёма на телефоне указывать раздельно.

Открытые P/D/R-пункты перечисляются при передаче кандидата. Push остаётся выключенным до реализации и подтверждения соответствующего канала. Решение о выпуске с отключённой функцией оформляется отдельно. Перенос проверки не означает прохождение приёмки блока 7 или разрешение публикации.
