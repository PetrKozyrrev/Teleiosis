# Requirements (MVP)

## Must-have
1. Регистрация через Telegram
2. Сохранение ссылок через бота
3. Сохранение пересланных сообщений (в поддерживаемых сценариях)
4. Определение типа материала
5. Базовые метаданные, если доступны
6. Библиотека в Mini App
7. Поиск
8. Фильтрация и сортировка
9. Создание и редактирование категорий
10. Привязка материалов к категориям
11. Изменение статусов (Не просмотрено / Запланировано / Изучено / Неактуально)
12. Удаление материалов
13. Напоминания через бота
14. Настройки напоминаний
15. Базовая статистика
16. Изоляция данных пользователей

## Should-have
Автополучение названия, описание и изображение, теги, заметки, ежедневная подборка, простые цели, быстрая смена статуса в боте.

## Later (не в MVP)
ИИ-суммаризация, семантический поиск, ИИ-помощник, учебные планы, тесты, интервальное повторение, нативные приложения.

## Критерий готовности
Пункты 1–15 из раздела 8 технического плана.
