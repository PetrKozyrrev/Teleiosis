# Requirements (MVP)

Обновлено 16.11.2026: исторические этапы 1–7 завершены; локальный закрытый тест пройден по сообщению основателя, серверный деплой ещё не выполнен. Ниже сохранены требования веб-MVP; требования первого мобильного релиза приведены отдельно.
Источник: Технический план v2, раздел 4. Критерий готовности: раздел 8 того же документа.

## Should-have
- Подтверждение e-mail: готово (обязательно до включения e-mail-напоминаний на боевом сервере).
- Закладка браузера для быстрого сохранения: готова (расширение браузера позже).
- Заметки к материалам: готово.
- Ежедневная подборка сохранённого контента: готово.
- Метрики закрытого тестирования (`python -m app.metrics`, активные дни): готово.
- Удаление аккаунта и выгрузка данных: готово (код, настройки). До публичного запуска уточнить у юриста состав выгрузки и срок хранения копий; ручная проверка не подтверждена.
- Простые цели, например «Изучить маркетинг».
- Тёмная тема.

## Later (не в MVP)
- Автоматическая категоризация и теги.
- ИИ-суммаризация, семантический поиск, ИИ-помощник.
- Учебные планы, тесты, интервальное повторение, сложные рекомендации.
- Мобильные приложения Android и iOS, расширение браузера.
- Вход через VK ID или Яндекс ID.
- Веб-пуши и дополнительные каналы уведомлений.
- Сохранение PDF-файлов, раздельные переключатели видов писем, настройка частоты уведомлений.
- Публичный лендинг (welcome.html) и страница тарифов (docs/pricing.md): после закрытого теста и релиза.
- Письмо об удалении аккаунта, потоковая выгрузка для больших библиотек.

## Авторизация
Решение от 15.11.2026: только e-mail и пароль, сессия сайта в HttpOnly cookie. Бот, Telegram Mini App, initData и Bearer-вход удалены. Telegram остаётся источником сохраняемых ссылок.

## Первый мобильный релиз: утверждено 16.11.2026

Блок 1 подтверждён, серверная подготовка ведётся на Timeweb Cloud. M19 ещё не закрыт полностью; реальная доставка и публичная приёмка отделены от приватных проверок. Подробности: [deployment.md](deployment.md).

Продолжение: сервер Timeweb и teleiosistest.tw1.ru уже выбраны, приватный HTTPS-staging проверен с синтетическими данными. 741 pytest и реальные verify/reset/reminder/digest через capture прошли, backup/restore и restart Docker проверены. M19 не закрыт полностью: публичный TLS, реальная внешняя доставка, отдельные копии и remote CI остаются открытыми. Временный режим описан в [staging.md](staging.md); capture не является подтверждением SMTP-доставки.

План: [mobile_plan.md](mobile_plan.md), целевые контракты: [architecture.md](architecture.md). Следующая матрица задаёт будущую приёмку; ни одна строка пока не считается пройденной на мобильном приложении. Существующие веб-функции не означают готовность mobile.

| ID / блок | Требование и acceptance criteria | Необходимая проверка |
|---|---|---|
| M01 / 2 | Приложение устанавливается и запускается на Android и iPhone; закреплены SDK, минимальные ОС и модели | Development/release-сборки, физические устройства, навигация |
| M02 / 3 | E-mail/пароль и тот же аккаунт на сайте/телефоне; mobile-токен не является web-cookie | Auth integration, 401/429, смешанные credentials, CSRF-регресс |
| M03 / 3 | Reset/verify по одноразовой ссылке, корректные сроки и web-fallback | Письмо, холодный запуск, просрочка, повтор, отзыв всех сессий при reset |
| M04 / 4 | Список, поиск по названию, фильтры, сортировка, страницы, пустые/ошибочные состояния | UI/API/E2E; устаревшие ответы поиска и большие списки |
| M05 / 4 | URL или заметка сохраняются без обязательных метаданных; дубль URL открывает существующий материал | Нет метаданных/изображения, 409 existing_id, неверный URL |
| M06 / 4 | Одна категория на материал, CRUD категорий, четыре свободных статуса | Переназначение, дубль имени, удаление категории сохраняет материалы |
| M07 / 4–5 | Изменение/удаление/открытие оригинала; устаревший PATCH обрабатывается явно | Параллельное web/mobile-редактирование, 404, атомарная версия, подтверждение удаления |
| M08 / 5 | Share принимает одну ссылку или текст и переживает отмену/холодный запуск; сохраняет черновик до входа | Android intent и iOS extension на физических устройствах, повтор события |
| M09 / 5 | Вне сети доступны загруженные материалы с отметкой актуальности, незагруженные не выдаются за доступные | Отключённая сеть, поиск по кэшу, перезапуск, повторная загрузка страницы |
| M10 / 5 | Очередь новых ссылок/заметок переживает restart; одна операция не создаёт дубликаты | Потерянный ответ после commit, два запроса, 429/5xx, late retry после удаления |
| M11 / 5–6 | Очередь изолирована по владельцу; 401 приостанавливает отправку; выход не теряет черновики молча | Истечение сессии, вход другим аккаунтом, выбор перед выходом |
| M12 / 6 | Напоминание назначается/переносится/отменяется с явным IANA-поясом | UTC/DST, будущее/лимиты, несовпадение пояса устройства и настроек |
| M13 / 6 | /stats отражает существующие показатели; фактическое время обучения не выдумывается | Пустые данные, статусы, граница локального дня, сверка с сервером |
| M14 / 6 | Смена пароля отзывает остальные сессии; экспорт доступен средствами ОС без секретов | Web/mobile-сессии, неверный пароль, содержимое JSON, ошибки сохранения |
| M15 / 6 | Удаление аккаунта очищает серверные данные и SQLite/SecureStore/App Group | Каскады, очередь, перезапуск, недоступность старого токена |
| M16 / 7 | Push на обеих ОС в согласованной конфигурации открывает материал после проверки прав | Permissions/отказ, cold start, token rotation, чужой/удалённый материал |
| M17 / 7 | Каналы управляются явно; retry учитывает отмену/изучение/TTL; выход отвязывает устройство | Сбой провайдера, несколько устройств, отключение канала, простой воркера |
| M18 / 4–8 | Интерфейс доступен: крупный текст, клавиатура, TalkBack/VoiceOver; нет секретов в логах | Компонентные и ручные проверки обеих ОС |
| M19 / 1, 8 | Сервер/почта/бэкапы проверены в реальной инфраструктуре; сайт совместим | CI, миграции, restore, smoke, регресс сайта, РФ-сети |
| M20 / 8 | Обновление приложения сохраняет кэш/очередь; релиз имеет подписанный артефакт и план отката | Upgrade E2E, release install, совместимость с предыдущим клиентом |

Не входят: полное офлайн-редактирование, загрузка PDF/медиа, цели/планы/ИИ/повторение, подписка и social login. PDF-URL сохраняется обычной ссылкой. Синхронизация серверных данных доступна всем тарифам. Тёмная тема остаётся последующим улучшением, первый релиз использует существующую светлую палитру.

Зависимости, пока не подтверждённые пользователем: бюджет/хостинг/домен/SMTP, юридическая схема, macOS и устройства, аккаунты магазинов, точное покрытие Android без Google, минимальные ОС. Их статус и критерии закрытия — в mobile_plan.md; не подменять отсутствующие ответы техническими предположениями.

## Согласованное продолжение: подблок 9А, 20.11.2026

После подтверждения APK 0.5.3 пользователь разрешил продолжить. Дополнение к первому релизу: несколько приватных тегов/коллекций у сохранённого материала, CRUD групп и AND-фильтры, экспорт и каскадное удаление без потери материалов. Назначение только онлайн и с версией; прежняя очередь новых материалов не меняется. Офлайн-фильтры по группам, импорт, PDF-файлы, новые функции web UI и ИИ не входят в 9А. Критерии и отдельные подблоки — [mobile_organization.md](mobile_organization.md). Прежние открытые платформенные/релизные проверки сохраняются.
