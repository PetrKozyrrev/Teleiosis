# Requirements (MVP)

Версия 2 от 08.11.2026 (сайт вместо Telegram Mini App).
Источник: Технический план v2, раздел 4. Критерий готовности: раздел 8 того же документа.

## Must-have

| № | Требование | Состояние на 08.11.2026 |
|---|---|---|
| 1 | Регистрация, вход и выход на сайте (предварительно e-mail и пароль) | Регистрация, вход и выход в backend готовы (cookie сессии, подшаги 6.2-6.3); интерфейса нет. Вход по Telegram initData заморожен | 
| 2 | Согласие на обработку персональных данных при регистрации | В backend готово (consent, consent_at, consent_version); текст согласия утверждает юрист, интерфейса нет |
| 3 | Восстановление доступа (сброс пароля по e-mail) | Не начато |
| 4 | Сохранение ссылок и заметок через сайт | Backend готов (POST /contents), интерфейса нет |
| 5 | Определение типа материала | Готово в backend (source, content_type) |
| 6 | Базовые метаданные, если доступны | Готово в backend |
| 7 | Просмотр библиотеки | Backend готов, интерфейса нет |
| 8 | Поиск материалов | Backend готов (по названию) |
| 9 | Фильтрация и сортировка | Backend готов |
| 10 | Создание, редактирование и удаление категорий | Backend готов |
| 11 | Привязка материалов к категориям | Backend готов |
| 12 | Изменение статусов (не просмотрено, запланировано, изучено, неактуально) | Backend готов |
| 13 | Удаление материалов | Backend готов |
| 14 | Напоминания | Не начато (таблица reminders есть, API и отправки нет) |
| 15 | Настройки напоминаний | Поля в users есть, API изменения настроек нет |
| 16 | Базовая статистика | Не начато |
| 17 | Изоляция данных пользователей | Готово в backend |
| 18 | Ограничение частоты запросов (вход, регистрация, сброс пароля) | Не начато |
| 19 | Адаптивный интерфейс: телефон и компьютер | Не начато |

## Should-have
- Подтверждение e-mail (обязательно до включения e-mail-напоминаний).
- Закладка или расширение браузера для быстрого сохранения.
- Заметки к материалам (в backend уже есть).
- Ежедневная подборка сохранённого контента.
- Простые цели, например «Изучить маркетинг».
- Удаление аккаунта и выгрузка данных (обязательно до публичного запуска).
- Тёмная тема.

## Later (не в MVP)
- Автоматическая категоризация и теги.
- ИИ-суммаризация, семантический поиск, ИИ-помощник.
- Учебные планы, тесты, интервальное повторение, сложные рекомендации.
- Мобильные приложения Android и iOS, расширение браузера.
- Вход через VK ID или Яндекс ID.
- Веб-пуши, мессенджер-каналы (развитие Telegram-бота, возможно MAX).

## Заморожено
Telegram-бот (bot/) и вход по Telegram initData (POST /auth/telegram) остаются в репозитории и под тестами, но не развиваются.
