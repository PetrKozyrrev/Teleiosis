# Technical decisions

| Дата | Решение | Почему |
|------|---------|--------|
| 03.11.2026 | Backend: Python + FastAPI | Простой, надёжный, автодокументация API, подходит для бота и Mini App |
| 03.11.2026 | БД: PostgreSQL | Предусмотрено техпланом; надёжная реляционная модель |
| 03.11.2026 | Один backend и одна БД для бота и Mini App | Единая бизнес-логика, без дублирования (требование техплана) |
| 03.11.2026 | Приватный репозиторий GitHub | Коммерческий проект |
| 03.11.2026 | Секреты только в .env, шаблон в .env.example | Токены не должны попадать в GitHub |
| 03.11.2026 | Порядок разработки: API → бот → Mini App | Снижение риска: сначала ядро, затем интерфейсы |
| 03.11.2026 | Одна категория на материал (category_id в contents) | Категория это тематика, теги это доп. метки; проще UI и статистика |
| 03.11.2026 | Теги не входят в MVP-схему | Should-have, добавим миграцией при необходимости |
| 03.11.2026 | UserSettings объединена с users | Связь 1:1, избегаем дублирования timezone |
| 03.11.2026 | Время хранится в UTC (TIMESTAMPTZ) | Корректная работа с часовыми поясами |
| 03.11.2026 | Уникальность (user_id, url_normalized) | Защита от дублей при повторном сохранении |
| 03.11.2026 | url может быть NULL, есть поле note | Пересланные сообщения и текстовые заметки без ссылки |
| 03.11.2026 | Alembic для миграций, адрес БД берётся из .env | Схема меняется только миграциями |
| 03.11.2026 | Тесты на отдельной БД teleiosis_test | Тесты не должны трогать рабочие данные |
| 04.11.2026 | Временная идентификация через заголовок X-Dev-Telegram-Id, включается флагом DEV_AUTH_ENABLED (по умолчанию выключен) | Позволяет разрабатывать API до этапа 5; эндпоинты зависят только от get_current_user, замена в одном месте |
| 04.11.2026 | Чужой ресурс возвращает 404, а не 403; дубли ловим через ограничение БД (409) | 404 не раскрывает существование чужих данных; нет гонки «проверить, потом вставить» |
| 04.11.2026 | Ссылки нормализуются (https, без www, трекинга, фрагмента; для YouTube только v/list; t.me без параметров); дубль даёт 409 с existing_id | Один материал не сохраняется дважды в разных видах; боту удобно показать уже сохранённое |
| 04.11.2026 | Принимаются только http/https, хост с точкой, без логина в ссылке | Защита от мусора и опасных схем; SSRF учтём при загрузке метаданных |
| 04.11.2026 | Список материалов: пагинация limit/offset (по умолчанию 20, максимум 100), в ответе total; к любой сортировке добавляется id | Просто для MVP; стабильный порядок между страницами |
| 04.11.2026 | Поиск только по названию через ILIKE с экранированием % и _; невалидные фильтры дают 422 | Соответствует требованиям MVP; пользовательский ввод не работает как шаблон |
| 04.11.2026 | Статус один на материал, переходы между статусами свободные; studied_at ставится при входе в «Изучено» и очищается при выходе | Просто для пользователя; даёт данные для статистики |
| 04.11.2026 | PATCH материала меняет только title, note, status, category_id; лишние поля дают 422; ссылка не редактируется | Защита от подмены user_id и обхода проверки дублей; ссылку проще пересохранить |
| 04.11.2026 | Идентификаторы в адресе ограничены диапазоном BIGINT (422 вместо 500) | Огромное число не должно ронять запрос ошибкой БД |
| 04.11.2026 | Метаданные ссылки (название, описание, картинка) загружаются синхронно при сохранении, тайм-аут около 6 с; при любой неудаче сохраняется временное название | Просто для MVP, название сразу корректное; позже можно вынести в фон |
| 04.11.2026 | Защита от SSRF: только публичные IP, http/https, порты 80/443, ручная проверка каждого редиректа (до 3), лимит 512 КБ | Сервер не должен обращаться во внутренние сети по ссылкам пользователей |
| 04.11.2026 | YouTube: метаданные через oEmbed, а не HTML-страницу | Страница видео может вести на экран согласия с cookie (ЕС) и дать мусорное название |
| 04.11.2026 | Известные ограничения: DNS rebinding не закрыт на уровне кода; запрос сохранения держит соединение с БД до нескольких секунд | При деплое (этап 8) закрыть исходящий доступ в частные сети и к адресу метаданных облака; боту ставить тайм-аут запроса не меньше 10 с |
| 04.11.2026 | Бот работает только через HTTP API, к базе не подключается; собственный файл настроек bot/config.py | Единая бизнес-логика (требование техплана); у бота нет пароля от БД |
| 04.11.2026 | Бот представляется API заголовками X-Bot-Key + X-Telegram-Id (+ X-Telegram-Username); ключ не короче 32 символов, иначе вход ботом отключён; сравнение через hmac.compare_digest; неверный ключ даёт 401 без перехода к dev-входу | Безопасная идентификация доверенного сервиса до этапа 5 |
| 04.11.2026 | BOT_API_KEY это почти мастер-ключ: только в .env, не в Mini App; перед деплоем заменить, API закрыть от внешнего доступа | Утечка ключа позволяет действовать от имени любого пользователя |
| 04.11.2026 | Бот отвечает только в личных чатах; тайм-аут запроса к API 15 с | Группы вне MVP; сохранение с метаданными может идти несколько секунд |
| 05.11.2026 | Прокси для Telegram задаётся явно настройкой TELEGRAM_PROXY и применяется только к запросам к Telegram; клиент бота к нашему API игнорирует системные прокси (trust_env=False) | aiohttp не читает переменные окружения с прокси; при VPN/прокси Telegram недоступен напрямую; на сервере настройка остаётся пустой |
| 05.11.2026 | Бот достаёт ссылки из entities Telegram (url, text_link) с учётом UTF-16, до 5 ссылок за сообщение; текст без ссылки не сохраняется | Надёжнее регулярных выражений; защита от случайных сохранений; ограничение времени ответа |
| 05.11.2026 | Ответы бота без parse_mode, ссылка в ответ не включается | Название приходит с чужого сайта, разметка не должна исполняться; нет лишнего превью |
| 05.11.2026 | Лимита частоты сообщений пока нет | Известное ограничение, добавить до деплоя |
| 05.11.2026 | Пересланное сообщение: пост публичного канала сохраняется как ссылка t.me/<канал>/<id> (название из первой строки, текст в заметке); иначе ссылки из текста; иначе заметка; без текста сохранять нечего | У материала есть адрес оригинала; правила предсказуемы |
| 05.11.2026 | Имя канала проверяется шаблоном до подстановки в адрес | Адрес собирается только из проверенных частей |
| 05.11.2026 | Заметки не проверяются на дубли | Нет адреса для сравнения; известное ограничение MVP |
| 05.11.2026 | Кнопки бота не хранят состояние и не доверяют callback_data; защита от чужих материалов это проверка владельца в API (чужой id даёт 404) | Просто и надёжно; кнопки работают после перезапуска бота |
| 05.11.2026 | Кнопки показываются, только если результат сообщения один материал; в списке категорий до 8 кнопок | Ясно, к чему относятся кнопки; ограничение размера клавиатуры |
| 05.11.2026 | Категории из бота: создание командой /category, назначение кнопкой; управление (переименование, удаление) только в Mini App | Минимум для MVP, остальное в рабочем пространстве |
